## Run locally

Setup, database tables, and environment variables are in **[INSTALL.md](INSTALL.md)**.

```bash
npm install
npm run dev
```

Create `.env.local` from the variable list in [INSTALL.md](INSTALL.md) before using contact, admin, or the database.

The app runs at [http://localhost:3000](http://localhost:3000).

Copy for the about section lives in [`src/app/about/content.js`](src/app/about/content.js). A machine-readable profile is in [`public/llms.txt`](public/llms.txt) and [`public/llms-full.txt`](public/llms-full.txt).
